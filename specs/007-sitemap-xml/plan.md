# Implementation Plan: Sitemap for Search Engine Discovery

**Branch**: `007-sitemap-xml` | **Date**: 2026-09-12 | **Spec**: [spec.md](./spec.md)

**Input**: Feature specification from `/specs/007-sitemap-xml/spec.md`

## Summary

Publish `sitemap.xml` at the site root listing every publicly reachable page (home, history, about,
and each reference-language detail page) across all three supported locales, with per-URL
`hreflang` alternates so crawlers map each page to its translated equivalents — the sitemap-level
counterpart to the `hreflang`/canonical tags `useLocaleSeoTags()` already emits per page. The file is
generated by a small Node script from the same sources of truth the app itself uses (the locale list
in `useLocale.js`, the route list in `router/index.js`, and the language slugs under
`content/languages/*.md`), wired into `npm run build` via a `prebuild` step so it writes into `public/`
before Vite's existing `public/` → `dist/` passthrough — the same mechanism already used for
`.htaccess`, `robots.txt`, and `llms.txt`. `robots.txt` gains one `Sitemap:` line pointing at it.

## Technical Context

**Language/Version**: JavaScript (ES modules), Node 20.19.2 — matches the existing project runtime;
no new language.

**Primary Dependencies**: None new. Reuses `SUPPORTED_CODES` (`src/composables/useLocale.js`), the
route list already declared in `src/router/index.js`, and the same `content/languages/*.md` slug
source `src/composables/useLanguages.js` reads via `import.meta.glob` (the generator script instead
reads the directory with Node's `fs`, since it runs outside Vite/the browser).

**Storage**: N/A — the sitemap is a generated static file, not persisted application data.

**Testing**: Vitest (existing `tests/unit/`) for the generator's pure URL-list-building logic;
Playwright (existing `tests/e2e/`) to confirm `robots.txt`'s new `Sitemap:` line, following the same
pattern as `tests/e2e/static-files.spec.js` from `006-pagespeed-report-fixes`.

**Target Platform**: Static site served over Apache (existing `public/.htaccess` SPA rewrite), built
by GitHub Actions and deployed over FTP — unchanged.

**Project Type**: Single front-end project (Vue 3 + Vite SPA) — unchanged; this feature adds one
build-time generation script, no new project.

**Performance Goals**: N/A — a one-time, build-time file-generation step with no runtime cost; the
resulting file is a few KB of static XML, no measurable effect on page load or crawl performance
beyond the intended discoverability improvement.

**Constraints**: The generated file MUST NOT require hand-editing when a page or language is added
(spec FR-004) — it MUST be derived entirely from the same source lists the app already uses, not a
separately maintained list.

**Scale/Scope**: 3 route kinds (home, history, about) × 3 locales = 9 entries, plus 5 reference
languages × 3 locales = 15 entries → 24 `<url>` entries today; scales linearly and automatically as
languages/pages are added.
