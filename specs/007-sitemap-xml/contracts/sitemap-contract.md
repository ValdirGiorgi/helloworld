# Contract: `public/sitemap.xml` and `robots.txt`'s `Sitemap:` line

## `sitemap.xml`

**Address**: `https://helloworld.valdir.dev.br/sitemap.xml` (site root, alongside `robots.txt` and
`llms.txt`).

**Format**: Standard sitemap XML protocol (sitemaps.org), with the `xhtml` namespace for language
alternates.

```xml
<?xml version="1.0" encoding="UTF-8"?>
<urlset xmlns="http://www.sitemaps.org/schemas/sitemap/0.9"
        xmlns:xhtml="http://www.w3.org/1999/xhtml">
  <url>
    <loc>https://helloworld.valdir.dev.br/en</loc>
    <xhtml:link rel="alternate" hreflang="pt-BR" href="https://helloworld.valdir.dev.br/pt-BR" />
    <xhtml:link rel="alternate" hreflang="en" href="https://helloworld.valdir.dev.br/en" />
    <xhtml:link rel="alternate" hreflang="es" href="https://helloworld.valdir.dev.br/es" />
    <xhtml:link rel="alternate" hreflang="x-default" href="https://helloworld.valdir.dev.br/en" />
  </url>
  <!-- one <url> per (page kind × locale), plus one per (language slug × locale) -->
</urlset>
```

**Guarantees** (verified by `tests/unit/generateSitemap.spec.js` and the manual build check in
`quickstart.md`):

- Root element is `<urlset>` with both the default sitemap namespace and `xmlns:xhtml`.
- Exactly one `<url>` per distinct page address — no duplicates (FR-003).
- Every `<url>` has exactly one `<loc>`, an absolute URL under `https://helloworld.valdir.dev.br`.
- Every `<url>` has exactly `SUPPORTED_CODES.length + 1` `<xhtml:link rel="alternate">` children: one
  per supported locale (`pt-BR`, `en`, `es`) plus one `hreflang="x-default"` pointing at the `en`
  address (FR-002) — mirroring `useLocaleSeoTags()`'s per-page `<head>` alternates.
- No `<priority>`, `<changefreq>`, or `<lastmod>` elements are present (research.md §5).
- Entry count equals `(number of page kinds) × (number of locales) + (number of language slugs) ×
  (number of locales)` — currently `3 × 3 + 5 × 3 = 24`.
- The file itself is never listed as one of its own `<url>` entries (spec Edge Cases).
- Regenerated by the `prebuild` npm script on every `npm run build`; not present in version control
  (research.md §2).

## `robots.txt`'s `Sitemap:` line

**Guarantee** (verified by an added assertion in `tests/e2e/static-files.spec.js`):

- `robots.txt` contains the line `Sitemap: https://helloworld.valdir.dev.br/sitemap.xml` in addition
  to its existing `User-agent: *` / `Allow: /` content (FR-005).
